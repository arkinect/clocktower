# Role panels

`web/src/storyteller/role-panels/` would hold a screen a generic spec cannot express, registered by role id.

There are none. All 55 roles run on the generic day actions, decisions, questions, setup fields and day notices. The Cannibal, Moonchild, Juggler and Gossip use day actions and decisions the roles declare.

If a panel is ever added, list it here with a line on why the generic specs could not carry it.
